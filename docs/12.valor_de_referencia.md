# Valor de referencia

The Catastro's value for each parcel, meant to be close to what it would sell for. It's set every year, and taxes on buying land use it as their minimum base.

## How it's calculated for rustic land
- **Starts from real sales:** sale prices reported by notaries give an average value per crop or land use in each area (módulo de valor medio). It covers every rustic use, forest included.
- **Adjusted for the parcel:** that average is corrected for location, agronomic and socioeconomic factors, so a parcel near a village is worth more than one in the middle of nowhere.
- **Set a bit below market on purpose:** a 0.9 factor is applied, so it's not the sale price. It's for comparing lots, not for predicting what one will sell for.

## How to get it

| Option | Result |
|---|---|
| Goolzoom | Only returns it for homes, not for land. Tried with `scripts/try_goolzoom_reference_value.py` and `scripts/try_goolzoom_value.py` |
| Catastro website | Works, but by hand, one parcel at a time, so it isn't practical |
| [CatastroAPI](https://catastroapi.com/) | Free API that returns it. Access has to be requested, and it was requested on 17 Nov 2026 |
