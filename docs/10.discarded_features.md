# Discarded features

Ideas that were interesting but not needed for this project. Kept here so the reasons aren't lost if they come up again.

## Marker clusters
Grouping nearby markers into a circle with a count (`markerClusterOptions()`), which splits as you zoom in.

- **Not needed:** there are only 50–100 active auctions across Spain, and fewer once the filters are applied, so plain markers read fine.
- **Costs clicks:** a cluster isn't a marker. To select a lot from the map you'd first have to click the cluster, sometimes twice, until its marker shows. Clicking a marker would still select its row.
- **The other use, seeing where more auctions happen**, is an analysis question, not a way to find a lot to buy.

If it's ever needed: `clusterOptions = markerClusterOptions(disableClusteringAtZoom = 12)` on the blue markers, so it only groups when zoomed out, and `clearMarkerClusters()` next to `clearMarkers()`, because `clearMarkers()` doesn't remove clustered markers.

## Historical PNOA as a base map
The IGN's aerial photos from earlier years, as one more base map.

- **Rarely useful when buying:** only to check one lot you're already interested in, e.g. whether a house on rural land already existed years ago (it can matter for whether it's legal), or whether the land was farmed, burnt or flooded.
- **A base map shows one year at a time**, and what's useful is comparing years. The IGN already does that with the [PNOA comparator](https://www.ign.es/web/comparador_pnoa/), which puts two dates side by side.

If it's needed, search the lot's location in the comparator. If it becomes frequent, a link from the selected lot to the comparator would be enough.

## Land use planning layer (visorSIU)
The Ministry's [Urban Information System](https://www.mivau.gob.es/urbanismo-y-suelo/sistema-de-informacion-urbana) (SIU) shows the planning classification of land for all of Spain: urbano, urbanizable or no urbanizable.

- **Not needed:** the table already shows each lot's use and class (urbano or rústico) from the Catastro, which is enough to decide whether a lot is worth a closer look.
- **One difference to keep in mind:** the Catastro's class is for taxes, while the SIU's is the town's plan. A plot can be rústico in the Catastro and still urbanizable in the plan.

If a lot looks interesting and you need to know whether it could be built on, check it in the visorSIU: https://www.mivau.gob.es/urbanismo-y-suelo/sistema-de-informacion-urbana

## Thicker Catastro parcel lines
The parcel lines of the Catastro overlay are thin and hard to see on the aerial photo.

- **Not easy to change:** the Catastro sends ready-made images, and its service only has one style for each layer, so the line width can't be changed from leaflet.
- **The only way is CSS in the app:** an outline around the lines of the image (`filter: drop-shadow(...)`), written inside the R code. Not worth adding CSS for this.
